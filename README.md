# 游戏内事件溯源与状态回放系统

## 项目描述

游戏内事件溯源与状态回放系统的bug修复项目。核心模块 `event_sourcing/event_store.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 事件追加完全没做发生了什么不记录
- 事件存储完全没做只有当前状态没有历史
- 状态回放完全没做不知道之前的状态是什么
- 投影完全没做查询数据要遍历所有事件
- 快照完全没做回放要从开头开始

## 运行测试

```bash
python -m pytest tests/test_event_store.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
